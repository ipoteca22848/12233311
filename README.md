# Chess Helper — Windows 10/11

Прототип: захват выделенной доски, калибровка фигур по текущей теме,
расчёт Stockfish, красная стрелка поверх экрана и кнопка выхода снизу панели.
Обработка локальная. Внешние подсказки запрещены в турнирах Chess.com;
используйте приложение для разрешённого анализа и тренировки.

## Получение EXE

После публикации кода в GitHub: Actions → Windows EXE → Run workflow.
Скачайте и распакуйте артефакт `ChessHelper-Windows` с `ChessHelper.exe`.
Python для запуска EXE не требуется. Workflow пока не запускался;
готовый Windows EXE в Linux-среде не собран и не приложен.

Локальная сборка на Windows с Python 3.11 из папки проекта:

```powershell
python -m pip install -r requirements.txt pyinstaller==6.12.0
python -m unittest discover -s tests
python -m PyInstaller --clean --noconfirm --onefile --windowed --name ChessHelper app.py
```

Результат: `dist/ChessHelper.exe`. Цифровая подпись не настроена.

## Использование

1. Скачайте и распакуйте официальный Stockfish для Windows:
   https://stockfishchess.org/download/ — выберите версию для своего процессора.
2. В помощнике выберите распакованный `stockfish.exe`.
3. Откройте стандартную начальную позицию, отключите анимацию ходов,
   уберите выделения/стрелки. Отметьте галочку, если чёрные снизу.
4. Выделите ровно квадрат 8×8 клеток без внешних координат и рамок.
   Esc отменяет выделение.
5. Оставьте панель вне доски и нажмите «Запустить».
6. «Остановить» скрывает стрелку. «Выход из помощника» закрывает приложение
   и процесс движка.

## Ограничения

- Нужна калибровка с начальной позиции. Произвольный скриншот середины партии
  не поддерживается. После смены темы, масштаба или ориентации повторите калибровку.
- Распознавание чувствительно к подсветке клеток, перекрытиям и курсору.
  При сомнении стрелка скрывается и показывается ошибка.
- Программа принимает только один легальный ход между захватами, сохраняя
  очередь хода, рокировки и взятие на проходе. Если пропущено несколько ходов,
  восстановите последнюю позицию или начните новую калибровку.
- Собственная стрелка скрывается перед захватом; возможно мерцание.
  Смешанный DPI нескольких мониторов требует проверки на целевой машине.
- Stockfish получает 0,6 секунды на ход. Дебютная база не включена.
  Победа или мат не гарантируются.
- Работа захвата, оверлея и EXE на Windows ещё не проверена.

Разработка: `python -m pip install -r requirements.txt`, затем `python app.py`.
Проверки: `python -m unittest discover -s tests`.
